# MediMap

MediMap is a diagnostic-service discovery and price-comparison project for Dhaka, Bangladesh.
This initial version has a static "Coming soon" page.

Built with React, TypeScript, TanStack Start, and Vite. Requires Node.js 22.12 or later.

## Run locally

```sh
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

## Checks

Use Oxlint for linting and `tsc` for TypeScript checking.

```sh
npm run typecheck
npm run lint
npm run build
```

Run `npm run lint:fix` to apply safe lint fixes.
